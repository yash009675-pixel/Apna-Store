# Phase 83 — Listing AI

Seller listing-assistance foundation using the existing OpenAI integration.

- AI-generated listing draft fields: title, descriptions, bullets, SEO title/description and keywords
- Uses seller-provided product information as the source
- Explicitly avoids inventing certifications, specifications, prices, stock, ratings or shipping promises
- Authenticated Edge Function with JWT verification
- Generation history stored securely for audit/admin review
- No automatic product publish/update action
- No paid AI service beyond the existing configured integration is added in this phase

Seller UI integration and broader AI automation remain follow-up work.
