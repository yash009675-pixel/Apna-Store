# Apna Store — UI-01 Design System

UI-01 establishes the shared visual foundation before page-by-page redesign.

## Design direction
- Premium, minimal, modern Indian e-commerce
- Warm off-white canvas with white surfaces
- Black primary actions and neutral secondary controls
- Inter typography
- Subtle borders and restrained shadows
- Consistent spacing, radii, controls and responsive gutters

## Responsive targets
- Small/mobile: 320–767px
- Tablet: 768–1023px
- Laptop/desktop: 1024–1439px
- Large desktop: 1440px+

## Shared tokens
CSS custom properties in `styles.css` define colors, spacing, radii, shadows, container widths, control height and transitions.

## Shared primitives
- `.apna-container`
- `.apna-content`
- `.apna-eyebrow`
- `.apna-title`
- `.apna-subtitle`
- `.apna-btn` with primary/secondary/ghost variants
- `.apna-card` / `.apna-panel`
- `.apna-field`
- `.apna-badge`
- `.apna-divider`
- `.apna-stack` / `.apna-row` / `.apna-grid`

UI-01 intentionally does not redesign individual pages. UI-02 onward will migrate the header, navigation and page layouts onto this foundation.
