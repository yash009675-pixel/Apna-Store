# Phase 79 — Security & Privacy

Free-plan security/privacy foundation.

- Privacy request registry for access, correction and deletion requests
- Authenticated users can create privacy requests through a protected RPC
- Admin-only request review/status RPCs
- Privacy request changes are audit logged
- Direct table access remains revoked; RPCs enforce authorization
- Request details are length-limited
- Completion timestamp is recorded
- No paid compliance service introduced

Final privacy/security review remains part of Phase 89 and final Phase 0 sign-off.
